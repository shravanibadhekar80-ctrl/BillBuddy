
# BillBuddy – Bill and Renewal Reminder

## Project Description
BillBuddy is a web-based billing and payment management
system developed using Python and Django.

It helps small businesses manage customers, create invoices,
record payments, and track pending balances.

## Technologies Used
- Frontend: HTML, CSS
- Backend: Python, Django
- Database: SQLite (current development version)

## Main Features
1. Dashboard
2. Add and Search Customers
3. Create Invoices
4. View Invoice List
5. Record Payments
6. View Payment History
7. Check Remaining Balance
8. Track Pending and Overdue Invoices

## Project Modules
- Accounts
- Customers
- Billing
- Payments

## Installation

1. Clone the repository.
2. Create a virtual environment.
3. Install the required packages.
4. Run database migrations.
5. Start the Django server.

Commands:

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Open http://127.0.0.1:8000/ in your browser.
